HƯỚNG DẪN ĐƯA TRANG CÀI ĐẶT LÊN MẠNG

Mục đích:
- Tạo MỘT đường link chung để gửi cho học sinh.
- Trang tự hiển thị hướng dẫn theo thiết bị và có nút mở ứng dụng hiện tại.
- Không sửa Code.gs, Index.html hoặc dữ liệu Google Sheets hiện có.

CÁCH ĐƯA LÊN GITHUB PAGES (miễn phí):
1. Đăng nhập hoặc tạo tài khoản tại https://github.com
2. Tạo repository mới, ví dụ: hanh-trinh-biet-on-cai-dat
3. Chọn Public và tạo repository.
4. Tải lên 4 tệp: index.html, manifest.webmanifest, sw.js, icon.svg.
5. Mở Settings > Pages.
6. Ở phần Build and deployment, chọn Deploy from a branch.
7. Chọn branch main và folder /(root), rồi Save.
8. Chờ GitHub Pages xuất bản. Link thường có dạng:
   https://TEN-TAI-KHOAN.github.io/hanh-trinh-biet-on-cai-dat/
   Thay TEN-TAI-KHOAN bằng tên tài khoản GitHub thật của thầy.
9. Mở link đó trên điện thoại để thử; chỉ gửi link sau khi đã kiểm tra.

GIỚI HẠN QUAN TRỌNG:
- Trang này không thể tự ý thêm biểu tượng lên màn hình; học sinh vẫn phải xác nhận theo quy định của Android/iOS/Windows.
- Đây là trang hướng dẫn/cài đặt lối mở nhanh. Nút mở ứng dụng dẫn đến Google Apps Script hiện tại.
- Việc cài trang này không biến Google Apps Script thành ứng dụng ngoại tuyến và không thay đổi dữ liệu.
- Trên iPhone, thường phải dùng Safari > Chia sẻ > Thêm vào MH chính.
- Không gửi link GitHub Pages cho học sinh trước khi kiểm tra đường dẫn thực tế.
